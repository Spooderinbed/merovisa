## What this is

Rebuild the signed-out marketing landing (`app/(marketing)/page.tsx`) in the
premium v7 "Cursor cadence on our own skin" style: a confident hero, then
alternating product sections each anchored by ONE real interactive artifact.
Every claim is either a labelled **sample** or a **sourced + dated** fact — the
page sells the product by *showing* it, honestly.

Spec is founder-locked ("looks good to me", 2026-07-08) and Codex (GPT-5.5,
xhigh) reviewed it twice; all blockers/should-fixes/nice-to-haves folded in
(spec commit `2f4c150`, changelog §14). Build is unblocked.

## Section cadence (spec §3)

1. Sticky header (brand · nav · Sign in)
2. Hero — confident headline + hand-drawn marker on "pay anyone", flat plum CTA,
   the **live verdict panel** (§4.4) in a bordered stage, proof strip
3. "From verdict to plan" (`id="how"`) — **plan-step accordion** (§4.5)
4. "Documents" (`id="what"`) — **interactive checklist** (§4.6)
5. "The guide" — **autoplay guide typewriter** (§4.7)
6. "Sourced & dated" (freshness band) — **freshness table** + verify-sweep (§4.8)
7. Close — **sparkle CTA** (§4.2)
8. Footer (text only)

## Locked invariants (do not violate)

- **Server-rendered FILLED rest state.** The reference builds DOM in JS from
  empty; our React build INVERTS that — server-render the *filled* state
  (verdict panel shows Aarav final cost, plan step 02 open, checklist 2/6
  checked, guide `ielts` exchange rendered, freshness rows pre-verified, fill
  widths set inline). JS only *enhances*.
- **Hydration parity.** Islands are `'use client'` but first client paint ==
  SSR. No `matchMedia` / `IntersectionObserver` / `requestAnimationFrame` /
  `Math.random` during render — all run only in `useEffect` post-mount (sparkle
  particles seeded post-mount only).
- **Honesty split.** Sample-student numbers carry NO sourced `verified` citation
  (sample cost is a `≈` estimate beside a "Sample profile" label); sourced facts
  always render `source · verified <month>`. Enforced via a discriminated
  `kind: 'sample' | 'sourced'` union. Freshness provenance is visible at rest,
  never gated behind a click.
- **Genuine Student (GS)** terminology — Australia replaced "GTE / Genuine
  Temporary Entrant" with the Genuine Student (GS) requirement in 2024. No
  user-facing "GTE" string anywhere.
- **No dead links.** No `href="#"`. Hero CTA + verdict "See full breakdown" +
  closing sparkle CTA all → `/assess`; "Sign in" → `/auth`; footer text only.
- **Preserve the signed-in redirect.** Server shell keeps
  `getUser()` → `redirect("/dashboard")` before any landing markup.
- **No em-dashes** in the landing copy modules (guard test).
- **Both themes** (`prefers-color-scheme` + `:root[data-theme]` wins both ways;
  dark uses `background-color` not `background` shorthand), **1160px** max width.
- **Three approved flat-rule exceptions only** (§4.1–4.3): hand-drawn hero
  marker, sparkle CTA (closing only), faint paper grain. Nothing else departs
  from flat; each degrades to a calm static state under reduced motion.
- **No-JS vs reduced-motion are split** (spec §4.4, §4.7): no-JS = complete
  default rest state (native radio path offered for zero-JS switching);
  reduced-motion-with-JS = interaction preserved, animation suppressed.
- Presentational slice only — **no scoring / API / DB / Zod / auth changes.**
