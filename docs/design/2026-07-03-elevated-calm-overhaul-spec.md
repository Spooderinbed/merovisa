# MyVisa full UI/UX overhaul — "Elevated calm" design spec

> Founder-approved 2026-07-03 (plan-mode session). This is the umbrella spec for the whole-app design overhaul. Slice numbering below (MV-87..101) is **provisional** — assign the next free board IDs when carving each card. Phase 0 cards MV-82..86 are filed on the board.

## Context

The founder wants every MyVisa surface at "million-dollar" production polish — Phantom-level craft — covering palette, typography, motion, mascot, landing, wizard, and all signed-in surfaces. Trigger: two design-playbook video breakdowns whose formulas now steer design (completion drive on real milestones, no-shame, competence-not-theater; never PBL/badges/leaderboards/streaks/variable-reward). Demographic: 17–24 Nepali students, mobile-first, often low-end Android — anxious people making a life decision, hence the trust-first "calm authority" ethos.

**Founder decisions (locked):**
1. **Direction — "Elevated calm" (Phantom pole).** Keep the calm-authority core (flat, thin borders, no gradients/shadows); reach premium via motion, micro-interaction, typographic craft. Not Duolingo-playful.
2. **Mascot — yes, shell surfaces only.** One GLOBAL character on landing, auth, empty states, error pages, guide avatar, milestone beats. Product body stays imageless; `docs/imagery-policy.md` gets a founder-gated amendment.
3. **Palette — full rebrand.** New palette replacing deep-teal/warm-paper, Mobbin-research-driven, still calm/flat. Verdicts stay word+colour bands (never %) with re-chosen colours; every token contrast-checked light+dark.
4. **Rollout — funnel first.** Phase 1 = landing + wizard + results + auth; Phase 2 = signed-in shell.
5. **Brand is globally neutral; corridor theming is a post-onboarding personalization layer.** The site must NOT read as "a Nepali website" — base brand is placeless, Phantom-standard ("we could be from anywhere"). Only after the user picks their home country in onboarding does the corridor theme activate (Nepal today; e.g. Canada later): **corridor mascot variant + a small set of accent tokens + copy nods** — base palette/type/motion stay global. Activation point: results page onward for anonymous users (home country known post-wizard); always-on for signed-in users (from profile).

## Design decisions to ratify in Phase 0 gates

- **Global mascot = an abstract, geometric migratory bird** (working name: "the Wayfinder") — species-neutral and placeless (Phantom-ghost-level abstraction: silhouette + minimal features, no real-world species markers), so the base brand could be from anywhere. Migration = the journey metaphor, honest globally; upright/composed posture fits calm authority. Rendered flat thin-stroke, 3–4 palette tokens, never plush-3D (differentiates from Duolingo's owl). Never blocks/nags/streaks; never beside a verdict. **Corridor variants = plumage skins on the SAME silhouette**: the Nepal corridor gets a danphe-crested/danphe-accent variant post-onboarding; future corridors get their own plumage. One character rig, one brand silhouette, corridor personality as a skin. Runner-ups considered: paper plane (Telegram collision), neutral orb/spark (generic, no journey story).
- **Motion: CSS-first, NO framer-motion/`motion` dependency** ("Motion v2" ADR). `motion/react` ≈30KB on a funnel serving low-end Android; every needed pattern (direction-aware step slides, two-beat reveal, staggers, ring draws) is CSS + `animation-delay` + React keys — the codebase already works this way, and the single global reduced-motion contract survives. Hard rule: animate **opacity/transform only**. Escape hatch: re-evaluate `motion/mini` (~5KB) only if Phase 2 chat streaming demands it.
- **Typography: keep Hanken Grotesk + IBM Plex Mono**; the gap is no formal scale (arbitrary `text-[Npx]` everywhere). Define ~9 `--text-*` steps (label 12.5 mono / caption 14 / body-sm 15 / body 17 / lead 19–21 / title-sm 24 / title 32 / display-sm / display clamp) + paired line-heights; ratchet-test `text-[` down.
